## 数据集说明
收集了正常轴承、单点驱动端和风扇端缺陷的数据。驱动端轴承实验以12000个样本/秒和48000个样本/秒的速度采集数据。所有风机端轴承数据以12000个样本/秒的速度采集。

数据文件为Matlab格式。每个文件包含风扇和驱动端振动数据以及电机转速。对于所有文件，变量名中的以下项表示:

## 数据集包括
- 正常基线数据

- 12k驱动端轴承故障数据

- 48k传动端轴承故障数据

- 风机端轴承故障数据

实验数据集仅使用12k驱动端轴承故障数据，其余数据集预处理与实验数据预处理一致。
